# sharecode 기능 이식 및 UI 정리 (2026-08-18)

## 배경

`D:\workspace\sharecode`(`com.cardtracker.app`, 1,086줄)는 MyCard와 같은 도메인의 축소판이다.
SMS/알림 → 파싱 → Room → 월별 그룹까지 구조가 겹치므로, 전체 소스를 읽고 **MyCard에 실제로 없는 것만**
골라 이식했다. 대상 단말은 플립(`R3CX705W62D`, SM-F741N).

## 이식 판단

| sharecode 기능 | 판단 | 근거 |
|---|---|---|
| 카드별 월 한도 + 초과 경고 (`CardLimit`) | **이식** | MyCard에 한도 개념이 전무. MyCard는 그룹이 카드 한 장 단위라 sharecode보다 유용 |
| 알림 접근 권한 배너 | **이식** | MyCard는 배너가 `NotificationListActivity`에만 있었다. 데이터 소스가 알림인데 메인엔 경고가 없었음 |
| 카드사 아바타 | **재설계 후 이식** | 원안(첫 글자 + `hashCode % 8색`)은 현대카드 3장이 전부 다른 색·비슷한 글자가 된다 |
| 월 네비게이션 | **이식(메인 화면)** | 알림 기반 보기에는 이미 있었고 메인에는 없었다 |
| 취소 행 배경 강조 | 이식 | 저비용 |
| 그룹 기본 펼침 | **이식 후 되돌림** | 8개 그룹 60건이 전부 열려 목록이 벽이 된다. MyCard 원래 동작(접힘)이 맞다 |
| dedupe 키 `(issuer, amount, date, merchant)` | **거부** | 같은 날 같은 가맹점 동일 금액 2회 결제를 삼킨다. v1.2.1.0에서 제거한 문제와 같은 계열 |
| 취소 합산 `filter { !isCancel }.sumOf` | **거부** | 취소를 차감이 아니라 무시한다. 승인 48,000 + 취소 -48,000 → 48,000이 된다 |
| 카드사 이름 목록 파서 | **거부** | 현대카드 3장이 한 덩어리가 된다. MyCard가 카드 단위로 더 정밀 |
| SMS 인박스 전체 재스캔 / MM-DD 연도 추론 | **거부** | 알림 ts를 쓰므로 불필요 |
| MVVM(ViewModel + StateFlow) 전면 도입 | **보류** | `MainActivity` 최소 수정 규칙과 충돌하고 지금 실익이 적다 |

## 추가한 것

### 1. 카드별 월 한도 (`limit/CardLimitStore.kt`, `ui/CardLimitDialog.kt`)

- 저장 위치는 `mycard_prefs`의 `card_limits`(Gson JSON `{"하나 매직 9207": 300000, ...}`).
  Room 테이블을 쓰지 않은 이유는 두 가지다 — ① `mycard_prefs`는 이미 Activity/Worker/Widget이
  공유하는 단일 소스라 위젯에서 바로 읽을 수 있다 ② 직전 릴리스에서 DB version 2→3을 올렸는데
  바로 v4 마이그레이션을 얹는 것을 피했다.
- 키는 그룹 이름(`card_filters.json`의 `card_company`)이다. 즉 카드사가 아니라 **카드 한 장** 단위.
- 초과 시: 헤더 배경 `errorContainer` + `⚠ +28,040원`. 여유 시: `잔여 N원`.
- 설정 진입점 두 곳 — 메인 `⋮ → 카드 한도`, 알림 기반 보기 상단 `⚙`.
- 빈 칸/0을 저장하면 해당 카드의 한도를 해제한다.

### 2. 카드 아바타 (`ui/CardBrand.kt`)

sharecode 원안을 쓰지 않고 다시 설계했다.

- **실제 카드 비율**(46×30dp, 라운드 7dp)의 미니 카드. 원형 아바타가 아니다.
- **브랜드 그라데이션 14종** — 현대(차콜)/신한(블루)/하나(틸)/롯데(레드)/삼성/국민(옐로)/우리/
  농협/BC/현백(버건디). 네이버 현대카드는 네이버 그린, SK 계열은 SK 레드로 갈라 같은 발급사라도
  눈으로 구분된다.
- IC 칩 + 상단 광택 + 반투명 흰 테두리.
- **라벨은 뒷 4자리 우선** (`9207` `0179` `8423`), 없으면 `네이버` `SK` `현백` `롯데`.
  MyCard의 그룹은 카드 한 장 단위이므로 첫 글자보다 뒷 4자리가 식별에 유용하다.
- 국민카드처럼 배경이 밝은 브랜드는 `onBrand`를 어두운 색으로 따로 지정해 대비를 확보.
- `하나카드 매출취소` 그룹은 카드가 아니므로 회색.

### 3. 알림 접근 권한 경고 (`notif/ListenerAccess.kt`)

이 앱의 모든 집계는 알림 접근 권한 하나에 달려 있다. 권한이 꺼지면 **에러 없이 조용히 멈추고**
화면에는 예전 합계가 남아 "금액이 안 맞는" 것처럼 보인다. 2026-07-29 조사에서 다룬
불일치 문제를 조용히 만드는 구조라 경고를 추가했다.

- 알림 기반 보기: 목록 위 빨간 배너 + "설정 열기"
- 메인: 기존 스낵바 패턴 재사용(`MainActivity` 최소 수정 원칙)
- 설정에서 켜고 돌아오면 `ON_RESUME`에 재확인해 배너가 사라진다
- `isListenerPermissionGranted`를 공용화하고 `NotificationListActivity`의 중복 선언을 제거
  (같은 패키지라 재선언 충돌)

### 4. 메인 화면 월별 보기

- 상단바 `‹ 2026년 8월 ›`, 미래 달은 버튼 비활성.
- `NotificationDao.getParsedSince` → `getParsedInRange(sinceTs, untilTs)`.
  기존 쿼리는 상한이 없어 **미래 ts 알림이 이번 달에 섞일 수 있었다.** 월 구간을 닫으면서 같이 해결.
- `readNotifCardGroups(context, monthOffset = 0)`.
- **위젯 가드** — 지난 달을 보는 중에 `LaunchedEffect(groups)`가 위젯 prefs를 덮어쓰면 위젯이
  과거 달 합계를 표시하게 된다. `monthOffset != 0`이면 위젯 갱신을 건너뛴다.

## 고친 것

### 회전 시 펼친 카드가 초기화됨

펼침 상태가 `remember { mutableStateOf(setOf<String>()) }`라 구성 변경(회전, 폴드 접기/펴기)마다
초기화됐다. `rememberSaveable`로 바꿨는데, `Set<String>`은 Bundle에 직접 저장되지 않으므로
`listSaver`를 끼웠다.

```kotlin
var expandedGroups by rememberSaveable(
    stateSaver = listSaver(save = { it.toList() }, restore = { it.toSet() })
) { mutableStateOf(setOf<String>()) }
```

검증: 세로 → 가로 → 세로 2회 회전 후에도 펼친 카드 1개만 펼친 채, 나머지 6개는 접힌 채 유지.

### 그룹 헤더가 3줄 이상으로 늘어남

한도 줄 때문만이 아니었다. 글꼴이 큰 단말에서 **카드명·건수·한도가 각각 줄바꿈**되어
하나 매직 9207은 6줄까지 늘어났다.

```
이전:  [9207] 하나 매직          328,040원 ⌄
              9207
              오늘 0 / 전체
              12
              ⚠ 한도
              300,000원 초과
              (+28,040원)

지금:  [9207] 하나 매직 9207     328,040원 ⌄
              오늘 0 / 전체 12    ⚠ +28,040원
```

- 1행 = 아이콘·카드명·금액, 2행 = 건수·한도. 2행이 아바타·금액과 폭을 경쟁하지 않는다.
- 모든 `Text`에 `maxLines = 1`, 카드명은 `TextOverflow.Ellipsis`.
- 한도 문구를 `⚠ +28,040원` / `잔여 N원`으로 짧게(`ui/CardLimitDialog.kt`의 `CardLimitStatus`).

### 한도 초과 색이 보이지 않음

헤더 `Row`의 `.background(secondaryContainer)`가 Card의 `containerColor = errorContainer`를
덮고 있어 초과 표시가 눈에 보이지 않았다. 헤더 배경 자체를 조건부로 전환했다.

## 확인한 것 (플립 R3CX705W62D)

- `./gradlew assembleDebug` 성공, 설치 후 크래시·예외 없음
- 아바타 7종 표시 확인 — 현백(버건디) 롯데(레드) SK(레드) 9207(틸) 0179(틸) 8423(블루) 네이버(그린)
- 모든 그룹이 2줄 유지, 한도 초과 그룹만 분홍 배경 + 빨간 `⚠ +28,040원`
- 회전 2회 후 펼침 상태 유지
- 월 네비게이션 `‹ 2026년 8월 ›` 동작

## 남은 것

1. `하나 브로드 0…`은 `maxLines = 1`이라 이름이 잘린다. 아바타에 `0179`가 있어 식별은 되지만,
   이름 스타일을 한 단계 줄여 다 보이게 할 수도 있다.
2. 메인과 알림 기반 보기가 기능이 거의 같아졌다(월 이동·한도·아바타). 알림 기반 보기에만 있는 것은
   **항목 수정/삭제**뿐이다. 두 화면을 합칠지는 별도 판단이 필요하다.
3. 위젯에는 한도 초과 표시를 넣지 않았다. `card_limits`가 prefs에 있으므로 위젯에서 바로 읽을 수 있다.
